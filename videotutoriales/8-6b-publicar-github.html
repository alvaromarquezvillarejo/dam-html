Videotutorial 6b: Publicar nuestras páginas en GitHub

Esta página está publicada con GitHub Pages desde el repositorio del curso.

Los pasos seguidos: crear el repositorio en GitHub, subir los archivos HTML y activar GitHub Pages en la configuración del repositorio (Settings > Pages, rama main).

La dirección pública tiene la forma usuario.github.io/repositorio/.
